# План Code Review для модуля discount.py

### 1. Цели ревью
* Обеспечение абсолютной точности финансовых расчетов скидок.
* Защита логики от фрода (несанкционированного суммирования скидок).
* Проверка граничных условий сумм корзины.

### 2. Измеримые критерии качества
* Полное отсутствие "магических чисел" (все коэффициенты вынесены в константы).
* Наличие валидации входных данных (проверка на отрицательные числа).
* Покрытие кода модульными тестами (минимально 85%).

### 3. Участники и роли
* **Tech Lead (@Pottrah):** Главный проверяющий, утверждает архитектурные решения.
* **Developer:** Автор кода, устраняет замечания.

### 4. Раздел эскалации споров
В случае возникновения разногласий между разработчиком и ревьюером, окончательное решение принимает Tech Lead проекта. Если спор касается изменения бизнес-логики, привлекается Product Owner.
